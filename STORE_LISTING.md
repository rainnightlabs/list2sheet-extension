# Chrome Web Store Listing Draft

## Product name

List2Sheet

## Short description

Turn web posts, comments, products, search results, lists and tables into clean spreadsheet data.

## Positioning

List2Sheet helps people who regularly copy information from websites into spreadsheets but do not want to write scraping code.

It works on many visible webpage structures and provides Manual Pick when automatic detection needs help.

## Long description

Turn the web page in front of you into clean spreadsheet-ready data.

List2Sheet can detect and structure many common webpage formats, including:

- tables and data grids
- repeated lists and cards
- product/result lists
- search results
- comments and discussion streams
- social post feeds on supported pages

A typical workflow is simple:

1. Open the page containing the data you need.
2. Click Scan page, or use Pick from page to select the right area.
3. Review and clean the detected rows.
4. Copy the data or export it in a spreadsheet-friendly format.

Useful cleanup tools include duplicate removal, obvious ad/sponsored-row filtering, URL tracking cleanup and multi-stage keyword filtering.

Free includes scanning, Manual Pick, preview, cleanup, Saved Settings and copying up to 100 rows as TSV.

List2Sheet Pro adds unlimited rows, CSV/JSON/Markdown/XLSX export, infinite-scroll collection and multi-page collection.

### Privacy-first workflow

Normal webpage extraction and file generation happen locally in your browser. List2Sheet does not require sending scraped page content to Rainnight Labs for normal extraction.

### Languages

The extension interface supports English and Simplified Chinese.
